# AGENTS.md

The project name is GoTAU in prose and docs. Lowercase `gotau` is for import paths, module names, and code.
The project is a modern UTAU-compatible singing voice synthesizer written in Go. It's designed to be fast, modern, modular, and easy to use, while staying backwards compatible with the existing UTAU ecosystem.

## Skills

All skills can be found in the `.agents/skills` directory. Each skill is a subdirectory with a `SKILL.md` file that describes the skill and its capabilities.
